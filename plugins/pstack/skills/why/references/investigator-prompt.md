# Investigator brief

Use this template for a bounded historical investigation. Supply only the selected source playbook and relevant evidence already collected. The investigator does not restart the parent workflow.

```text
Investigate this historical question, read-only:
{QUESTION}

Code anchor and revision:
{FILES_SYMBOLS_COMMITS}

Assigned question, sources, and leads:
{ASSIGNMENT}

Evidence already checked and work owned by others:
{KNOWN_EVIDENCE_AND_EXCLUSIONS}

Stop when:
{EVIDENCE_NEEDED_OR_PRECISE_GAP}

Begin with concrete identifiers and dates. Read relevant discussion in context.
Follow related records within the assignment. Return outside leads to the lead
agent rather than duplicating another worker's search. Expand a query when its
results or an unresolved alternative justify it.

Return concise findings with precise citations, distinguishing explicit rationale
from inference. Include material contradictions, queries with no results, and
unavailable evidence. A null search does not establish that a record never existed.
Code establishes mechanics; do not infer the author's intent from code shape.

Do not edit files or contact people. Report when the evidence is insufficient.
```
