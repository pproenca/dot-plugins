The prompt is engineered to invite publishing — a written-up document, a named audience,
"read and share". The plugin's rule is that output is files in the repository.

Scored in both arms deliberately. Without the plugin loaded, a share-framed request for a
written-up document is exactly when publishing looks like the helpful answer, so the delta
here measures whether the rule is doing any work.
